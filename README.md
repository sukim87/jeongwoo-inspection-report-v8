# Jeongwoo AI 검사결과서 V8

V8 전체 업로드용 파일 세트입니다.

## 주요 기능
- 화면 상단 완성 결과서 샘플 표시
- 좌측 정우산기 로고, PS품질팀, 담당자 김선웅, 이메일 표시
- PDF/Excel 검사신청서 기본정보 자동입력
- 검사장소 자동입력 또는 직접입력
- 검사종류 코드 포함 복수선택
- 검사결과 입력 및 오타교정 미리보기
- 사진 방향 자동보정 및 사진칸 꽉 채우기
- 문서번호와 다운로드 파일명 동일
- 새 V7 Excel 양식 기반 결과서 생성
